# Fox的品控问题

随机抽取2袋剩余的橡皮筋里面统计发现：

在拉长37mm的条件下，拉力偏离很大(13%)，良品率只有约95%。

| 拉力规格              | 数量  |
| ----------------- | --- |
| 170g(6oz)         | 67个 |
| 150g(5.3oz)       | 30个 |
| 不合格(<5oz or >6oz) | 7个  |

## Zebra

在拉长37mm的条件下，简单测试20个，几乎达不到我的预期力量。

| 拉力规格        | 数量  |
| ----------- | --- |
| 170g(6oz)   | 2个  |
| 150g(5.3oz) | 6个  |
| 不合格(<5oz)   | 12个 |

## Panda
